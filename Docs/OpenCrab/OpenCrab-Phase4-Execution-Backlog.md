# OpenCrab Phase 4 执行 Backlog

## 1. 文档目的

本文为 Phase 4 组织级治理的可执行看板骨架。进入条件与目标以 [OpenCrab-Roadmap](OpenCrab-Roadmap.md) 第 7 节为准；待 Phase 3 签收或 E3/E4 核心交付后，可在此 Backlog 中细化 Epic、Story、DoD 与依赖。

## 2. Phase 4 总目标

- **组织身份接入**：SSO/IdP、组织-工作区映射，企业统一登录与角色同步。
- **组织级策略与权限**：跨工作区的角色与策略继承、合规策略可配置。
- **数据分级与保留**：数据分级策略、保留策略可配置并生效，可审计。
- **密钥与数据治理**：KMS、BYOK 或等效能力，敏感数据治理方案落地。

## 4. 非目标（Phase 4 不做）

- 多租户计费与用量计费（归属 Phase 7）。
- 跨区域/多集群部署与同步（归属 Phase 7）。
- 开放市场与第三方技能上架（归属 Phase 7）。

## 5. 验收与退出条件

- 企业可通过 IdP 统一登录并映射到工作区/角色。
- 组织管理员可配置跨工作区的策略与合规策略。
- 数据分级与保留策略可审计、可追溯。
- 密钥与敏感数据治理方案落地并可审计。

## 6. 下一步

- 进入 Phase 4 前，需完成 Phase 3 签收或 E3/E4 核心交付。
- 与试点确认组织级治理需求后，将本 Backlog 中的 Story 细化并排期。
