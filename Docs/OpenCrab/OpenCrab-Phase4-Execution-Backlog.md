# OpenCrab Phase 4 执行 Backlog

## 1. 文档目的

本文为 Phase 4 团队复制与轻治理的可执行看板骨架。进入条件与目标以 [OpenCrab-Roadmap](OpenCrab-Roadmap.md) 第 7 节为准；待 Phase 3 签收或 E3/E4 核心交付后，可在此 Backlog 中细化 Epic、Story、DoD 与依赖。

## 2. Phase 4 总目标

- **SSO-lite**：最小企业登录接入（OIDC 或 SAML 任选其一），不做复杂 SCIM 同步；企业账号可统一登录并映射到工作区/角色。
- **工作区/策略/技能/知识模板**：模板完善与复用，新团队可通过模板快速开通并复用策略与技能。
- **轻治理**：统一审计留痕、基础保留策略、基础角色模型；审计与基础保留策略可配置、可追溯。

## 4. 非目标（Phase 4 不做）

- SCIM、复杂组织级策略继承、数据分级体系、KMS/BYOK（归属 Phase 7 企业扩展包）。
- 多租户计费与用量计费（归属 Phase 7）。
- 跨区域/多集群部署与同步（归属 Phase 7）。

## 5. 验收与退出条件

- 企业账号可统一登录并进入对应工作区。
- 新团队可在标准模板上快速开通并复用策略与技能。
- 审计留痕与基础保留策略可审计、可追溯。

## 6. 下一步

- 进入 Phase 4 前，需完成 Phase 3 签收或 E3/E4 核心交付。
- 与试点确认「多团队复制」或「企业账号登录」需求后，将本 Backlog 中的 Story 细化并排期。
