# OpenCrab Phase 1 Pilot Acceptance Pack

## 1. 文档目的

本文用于定义 `Phase 1` 试点验收包，供产品、技术、安全与试点团队共同签收。范围只覆盖三个试点场景：

- 企业代码库问答
- 轻量 PR review
- 新人 onboarding 问答

## 2. 验收角色

| 角色 | 职责 |
| --- | --- |
| `PM` | 组织 UAT、汇总结论 |
| `Tech Lead` | 协调联调与技术签收 |
| `Sec` | 审计与外发策略验收 |
| `WorkspaceAdmin` | 工作区配置、技能与模型权限确认 |
| `Pilot Reviewer` | 试点团队体验反馈 |

## 3. 试点前置条件

- 已指定 1 个试点工作组
- 已绑定至少 2 个代码仓和 1 个文档源
- 已冻结模型白名单、工具白名单与最小审批矩阵
- 已配置 1 个内网模型网关与 1 个外部模型回退

## 4. 场景 A：企业代码库问答

### 4.1 用例

| 编号 | 测试问题 | 输入要求 | 预期结果 |
| --- | --- | --- | --- |
| QA-01 | 如何调用内部短信接口 | 来自试点仓库的真实模块问题 | 返回可执行建议并附带代码来源 |
| QA-02 | 支付回调并发处理逻辑在哪 | 指向真实目录或模块 | 返回模块说明与来源引用 |
| QA-03 | 当前工作区是否允许外部模型回退 | 模型策略查询型问题 | 返回符合当前工作区策略的解释 |

### 4.2 验收标准

- 回答带来源引用
- 回答优先走内网模型
- 若知识不足，返回明确说明而非幻觉式答案

## 5. 场景 B：轻量 PR Review

### 5.1 用例

| 编号 | 场景 | 输入要求 | 预期结果 |
| --- | --- | --- | --- |
| PR-01 | 一般规范问题 | 真实 PR diff | 返回规范建议并写回 PR 或管理台 |
| PR-02 | 安全风险问题 | 含高风险语句样例 | 返回风险说明并进入审计 |
| PR-03 | 正常 PR | 风险较低 PR | 产生 review 结果但不误拦截 |

### 5.2 验收标准

- 至少 1 个真实仓库跑通 webhook/bot 闭环
- review 结果可追溯到工作区与 trace id
- 高风险命中可在审计中检索

## 6. 场景 C：新人 Onboarding

### 6.1 用例

| 编号 | 测试问题 | 输入要求 | 预期结果 |
| --- | --- | --- | --- |
| ONB-01 | 核心模块目录结构说明 | 基于真实仓库结构 | 返回模块说明与来源 |
| ONB-02 | 某个内部流程在哪定义 | 关联代码与文档 | 返回代码 + 文档双来源 |
| ONB-03 | 如何开始本地联调 | 基于现有文档 | 返回真实文档引用或配置位置 |

### 6.2 验收标准

- 回答可帮助新人定位到真实文件或文档
- 至少一个回答同时引用代码与文档

## 7. 治理与合规模块验收

### 7.1 审计

- 能按 `workspaceId`、`userId`、`eventType`、时间区间查询
- 模型、工具、技能、外发事件都有记录

### 7.2 最小审批

| 编号 | 审批类型 | 预期结果 |
| --- | --- | --- |
| APV-01 | 高风险技能首次启用 | 返回 `pending approval`，审批后恢复或终止 |
| APV-02 | 受限内容外发 | 返回审批单号，审批人和结果可追溯 |

## 8. 指标阈值

| 指标 | 目标值 |
| --- | --- |
| 周活跃率 | `>= 60%` |
| 问答满意度 | `>= 70%` |
| 内网模型命中率 | `>= 80%` |
| 审计事件完整率 | `>= 95%` |
| 问答平均时延 | `<= 15s` |

## 9. 失败判定

出现以下任一情况，`Phase 1` 不能签收：

- 内网模型无法支撑核心问答场景
- 审计链路缺失，无法追溯关键操作
- 审批触发后无法恢复或终止任务
- 工作区隔离失效，存在越权风险
