# OpenCarb Phase 2 PRD

## 1. 文档目的

本文定义 `Phase 2` 的产品目标：在 `Phase 1 MVP` 基础上，补齐企业采购真正关心的增强治理能力，使 OpenCarb 从“可试点”进入“可扩展、可复制”的企业化阶段。

## 2. Phase 2 目标

- 把 `Phase 1` 的两类最小审批升级为可配置审批能力
- 把技能治理从“启停 + 锁版”升级为“发布、审核、灰度、回滚”
- 把异步任务从局部能力升级为统一作业系统
- 建立面向管理者的指标与成本视图
- 将 PR review 从轻量 webhook 提升到可配置集成能力

## 3. 目标用户

- `PlatformAdmin`
- `SecurityAdmin`
- `WorkspaceAdmin`
- 试点扩展后的第二批团队管理员

## 4. 核心需求

### 4.1 通用审批

- 支持按事件类型、风险级别、工作区策略配置审批流
- 支持多审批人、多状态、超时与回退
- 审批结果必须能恢复或终止挂起任务

### 4.2 技能治理增强

- 技能来源分层：官方、私有、第三方
- 技能版本、发布批次、灰度范围、回滚记录可追溯
- 工作区只消费已批准的技能视图

### 4.3 作业编排

- 统一承载索引任务、批量 review、审批后续执行、定时任务
- 支持重试、幂等、优先级和死信处理

### 4.4 可观测性与成本

- 管理台可查看采纳率、质量、成本、外发比例、审批触发率
- 支持按工作区、入口、模型、技能、作业维度聚合

### 4.5 PR review 深化

- 支持更完整的 review 模板、规则集、回写策略和结果归档
- 支持按仓库/分支/规则分层配置

## 5. 非目标

- 不做全公司统一审批平台
- 不做通用项目管理系统
- 不做多租户 SaaS 商业化计费能力

## 6. 成功指标

| 指标 | 目标 |
| --- | --- |
| 审批超时率 | `< 5%` |
| 技能回滚可执行率 | `100%` |
| 作业重试成功率 | `>= 80%` |
| 管理台指标覆盖率 | `>= 90%` |
| PR review 规则命中可解释率 | `>= 80%` |

## 7. 进入条件

- `Phase 1` 已完成试点闭环
- 指标与审计链路稳定
- 已形成首批治理反馈

## 8. 退出条件

- 至少 2 个团队可复用增强治理能力
- 审批、技能治理、作业系统、指标、PR review 五个模块均进入稳定可用状态
