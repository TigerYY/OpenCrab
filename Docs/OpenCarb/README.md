# OpenCarb 文档索引

本目录存放 `OpenCarb` 的首批产品与架构文档，围绕“基于 `OpenClaw` 打造企业团队级 AI 助理平台”的方向展开。

## 文档列表

- `OpenCarb-PRD.md`
  - 产品定位、目标用户、核心需求、非目标和成功指标。
- `OpenCarb-V1-Scope.md`
  - V1 必做范围、试点建议、验收标准和不做项。
- `OpenCarb-Architecture.md`
  - 系统分层、控制面职责和核心数据对象。
- `OpenCarb-Runtime-Integration.md`
  - `OpenClaw` runtime、ACP 和 skills 的复用方式与适配边界。
- `OpenCarb-Deployment-Security.md`
  - 内网优先、外部 API 备援的部署拓扑与安全边界。
- `OpenCarb-Roadmap.md`
  - 从试点到规模化复制的路线图。

## 推荐阅读顺序

1. 先读 `OpenCarb-PRD.md`
2. 再读 `OpenCarb-V1-Scope.md`
3. 再读 `OpenCarb-Architecture.md`
4. 然后读 `OpenCarb-Runtime-Integration.md` 和 `OpenCarb-Deployment-Security.md`
5. 最后读 `OpenCarb-Roadmap.md`
